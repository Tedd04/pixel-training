PIXEL TRAINING – INSTALLIERBARE WEB-APP (PWA)

Dateien:
- index.html: App
- manifest.webmanifest: App-Metadaten
- service-worker.js: Offline-Caching
- icons/: App-Symbole

WICHTIG:
Eine PWA lässt sich auf dem iPad nicht durch Öffnen einer ZIP-Datei als App installieren.
Die Dateien müssen zuerst auf einer HTTPS-Webadresse veröffentlicht werden.

Installation auf dem iPad:
1. Öffne die veröffentlichte HTTPS-Adresse in Safari.
2. Tippe auf „Teilen“.
3. Wähle „Zum Home-Bildschirm“.
4. Aktiviere bei Bedarf „Als Web-App öffnen“ und tippe auf „Hinzufügen“.

Danach erscheint Pixel Training wie ein eigenes App-Symbol auf dem Home-Bildschirm.
Für eine echte native App im Apple App Store wären zusätzlich ein iOS-Projekt, Apple-Signierung und der Veröffentlichungsprozess nötig.
